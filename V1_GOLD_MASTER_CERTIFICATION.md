1. Run database migrations: `npm run migrate`
2. Clear cache: `npm run cache:clear`
3. Rebuild frontend: `npm run build`
4. Deploy: `pm2 restart kayad-backend`

## 9.4 Rollback Procedure

### Quick Rollback (<15 minutes)

```bash
# Revert to previous version
git checkout v1.0.0
npm install
pm2 restart kayad-backend

# Verify
curl https://api.kayad.com/health
```

### Full Rollback (<1 hour)

```bash
# 1. Stop current deployment
pm2 stop kayad-backend

# 2. Restore database (if needed)
./scripts/restore-database.sh --backup=v1.0.0

# 3. Redeploy
git checkout v1.0.0
npm install
pm2 start kayad-backend

# 4. Verify
./scripts/health-check.sh
```

## 9.5 Deployment Guide

### Pre-Deployment Checklist

- [ ] All sign-offs obtained
- [ ] Security fixes applied
- [ ] Database migrations tested
- [ ] Environment variables configured
- [ ] Monitoring active
- [ ] Support team on standby
- [ ] Rollback plan tested

### Deployment Steps

```bash
# 1. Final backup
./scripts/backup.sh --type=full

# 2. Enable maintenance mode
kubectl set env deployment/kayad MAINTENANCE_MODE=true

# 3. Run migrations
cd backend && npm run migrate

# 4. Deploy backend
pm2 restart kayad-backend

# 5. Deploy frontend
vercel --prod

# 6. Disable maintenance mode
kubectl set env deployment/kayad MAINTENANCE_MODE=false

# 7. Health check
curl https://api.kayad.com/health
```

### Post-Deployment Verification

```bash
# Verify all critical paths
./scripts/verify-deployment.sh

# Check logs
pm2 logs kayad-backend --lines 50

# Check metrics
curl https://api.kayad.com/health
```
